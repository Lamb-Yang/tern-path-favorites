# path-favorites

Tern 路径收藏插件：在当前 tab 的分屏面板显示当前工作路径、搜索已收藏目录，并在新 tab 中打开收藏目录。

## 使用

- 状态栏的「收藏」按钮、palette，或 `ctrl+alt+shift+f`：在当前 tab 右侧打开路径面板。
- 面板顶部显示当前工作路径，并随终端焦点和路径变化更新；打开面板时搜索框已聚焦，直接打字即可筛选。
- 「收藏当前」收藏面板显示的当前工作路径；「浏览新增」打开目录浏览器（进入子目录、`..` 返回上级、选「收藏此目录」保存）。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 上下选择 | `↑` `↓` |
| 在新 tab 打开 | `Enter` 或双击 |
| 在 Finder 中显示 | `Shift+Enter` |
| 复制路径到剪贴板 | `Cmd/Ctrl+C` |
| 删除并撤销 | `Delete`，再按 `Cmd/Ctrl+Z` 恢复 |
| 清空搜索 | `Esc` |

右键单击任一收藏项还有「在新 tab 打开 / 复制路径 / 在 Finder 中显示 / 删除」菜单。

收藏数据保存在 Tern 的 `tern.kv` 中，插件重启后仍然保留。
